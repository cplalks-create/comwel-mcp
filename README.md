# comwel-mcp — 근로복지공단 산재판례·질병판정서·심사결정서 MCP

Claude가 근로복지공단의 **업무상질병 판정서**, **산재 심사청구 결정서**, **산재 판례 판결문**을 직접 검색하고, 원문을 읽고,
인용할 문장이 원문과 글자 그대로 같은지 대조할 수 있게 해 주는 MCP 서버입니다.

> - 근로복지공단의 공식 도구가 아닙니다. 공단이 [공공데이터포털](https://www.data.go.kr)에 공개한 API를 이용하는 개인 제작 도구입니다.
> - 검색 결과는 판단을 돕는 참고 자료이며 법률 자문이 아닙니다. 서면에 인용할 때는 반드시 원문을 확인하세요.

## 무엇을 할 수 있나요

Claude에게 이렇게 물어보면 됩니다.

- "급식실 조리흄 폐암으로 **인정**된 질병판정서 찾아줘"
- "교대제 근무자 뇌출혈 산재 판례 중 공단 처분이 **취소**된 사건 보여 줘"
- "특수고용 기사의 근로자 여부가 쟁점이었던 심사청구에서 원처분이 **취소**된 결정서 보여 줘"
- "판정위 사건번호 240020210001716 판정서 전문 보여 줘"
- "이 문장이 판결문 원문과 똑같은지 확인해 줘: …"
- "방금 찾은 판정서 3건을 `D:\사건\홍길동` 폴더에 PDF로 저장해 줘" → [근거자료용 PDF 저장](#근거자료용-pdf-저장)

| 자료 | 불복 단계 | 공공데이터포털 API | 건수(2026. 10. 기준) | 검색 방식 |
|---|---|---|---|---|
| 업무상질병 판정서 | 공단 판정 | [근로복지공단_질병판정서 조회 서비스](https://www.data.go.kr/data/15110836/openapi.do) | 약 6만 1천 건 | 공단 서버에서 실시간 검색 |
| 산재 심사결정서 | 심사청구 | [근로복지공단_심사결정서 조회 서비스](https://www.data.go.kr/data/15110818/openapi.do) | 3,000건 (2017년 접수 사건 일부만) | 공단 서버에서 실시간 검색 |
| 산재 판례 판결문 | 소송 | [근로복지공단_산재보험 판례 판결문 조회 서비스](https://www.data.go.kr/data/15041878/openapi.do) | 약 3만 5천 건 | 설치할 때 전체를 PC에 받아 두고 검색 (API에 검색어 기능이 없음) |

> 중간 단계인 **산재보험재심사위원회 재결**과 **행정심판 재결**은 이 MCP에 없습니다.
> [korean-law-mcp](https://github.com/chrisryugj/korean-law-mcp)처럼 법제처 자료를 다루는 MCP로 찾을 수 있습니다.

### 도구(기능) 목록

| 도구 | 하는 일 |
|---|---|
| `search_disease_rulings` | 질병판정서 검색 — 본문 검색어, 업종(산재보험 사업종류), 심의결과, 질병구분, 직종 |
| `get_disease_ruling` | 질병판정서 전문 보기 + 공단 공개 사이트에서 확인한 **공식 판정번호·판정일** (전문은 한 번 검색해 본 판정서만 — API에 사건번호 조회 기능이 없음) |
| `search_review_decisions` | 심사결정서 검색 — 본문 검색어, 사건명, 심사결과, 청구유형, 쟁점유형 |
| `get_review_decision` | 심사결정서 전문 보기 (한 번 검색해 본 결정서만) |
| `search_precedents` | 판례 검색 — 본문 검색어, 판결결과, 사건유형, 사고/질병 구분, 법원, 사건명 |
| `get_precedent` | 판결문 전문 보기 + 공단 공개 사이트에서 확인한 **재판부·선고일** |
| `verify_quote` | 인용하려는 문장이 원문에 글자 그대로 있는지 대조 (띄어쓰기·줄바꿈 차이만 무시) |
| `save_pdf` | 판정서·판결문·심사결정서를 **사건 근거자료용 PDF로 저장** (한 번에 최대 20건, 저장 폴더 지정 가능) |
| `list_codes` | 검색 조건에 넣을 분류 값과 건수 보기 |
| `update_precedents` | 판례 보관본을 **지금 바로** 다시 받기 (1~2분). 평소에는 [자동 갱신](#판례-자동-갱신)되므로 쓸 일이 거의 없음 |
| `precedent_update_log` | 판례 자동 갱신 기록(최근 30건)과 다음 확인 날짜 보기 |

### 검색어 쓰는 법

| 쓰는 법 | 뜻 | 예 |
|---|---|---|

## 자료의 한계 (꼭 읽어 주세요)

실제 데이터를 조회해 확인한 사항입니다.

- **API에는 날짜가 없습니다.** 그래서 판정서의 **공식 판정번호·판정일**과 판례의 **재판부·선고일**은 전문을 볼 때(`get_disease_ruling`·`get_precedent`)
  근로복지공단 공개 사이트([질병판정서](https://jilbyungcase.comwel.or.kr/)·[산재판례](https://sanjaecase.comwel.or.kr/))에서 확인해 함께 보여 줍니다.
  심사결정서는 공개 사이트가 없어 결정일을 확인할 수 없습니다(본문에 적힌 날짜만 참고).
- **정신질환·자살 판정서는 사실상 공개되지 않았습니다.** 공개 판정서 중 정신질환 2건, 자해행위(자살 포함) 2건뿐입니다.
- **심사결정서는 2017년 접수 사건 중 일부 구간 3,000건만 공개되어 있습니다.** 사건번호가 20170006001~20170009097 한 구간에 모여 있고,
  원처분은 대부분 2017년, 결정은 2017~2018년입니다. **2018년 이후 사건은 없으니** 최근 경향으로 일반화하지 마세요.
  최근 사례는 공단 홈페이지 [실무자료]의 연도별 「심사결정사례집」(PDF)을 직접 내려받아 Claude에게 주는 방식으로 보완할 수 있습니다.
  (2026. 10. 30. 실측: 3,000건 뒤 쪽은 0건이 와서, API가 잘라 보여 주는 것이 아니라 공개분 자체가 3,000건임을 확인)
  공개분의 심사결과는 기각 2,508건, 취소 361건, 일부취소 93건, 각하 37건, 취하 1건입니다.
- **판례 약 6,500건은 '취하' 사건**이라 판결문 본문이 없습니다.
- **판결결과는 공단 처분을 기준으로 적혀 있습니다.** 기각 = 대개 근로자 패소, 취소 = 대개 근로자 승소입니다.
  **예외:** 사업주가 원고로 공단의 승인을 다툰 사건(사건명이 '요양결정처분취소' 등이고 근로자가 '피고보조참가인')에서는
  '취소'가 **근로자 패소**입니다(예: 전주지방법원 2014구합2765). 원고가 누구인지 꼭 확인하세요.
- **판정서·심사결정서 검색은 띄어쓰기를 구분합니다.** "조리흄"과 "조리 흄"은 각각 찾아야 합니다. (판례 검색은 띄어쓰기를 무시합니다.)
- 판정서의 '업종'은 사업장 이름이 아니라 **산재보험 사업종류 이름**입니다. (예: 학교급식 → "국가 및 지방자치단체의 사업")
- 판정서·판결문의 개인정보는 공단이 ○○○ 등으로 가려 두었습니다.

## 근거자료용 PDF 저장

찾은 판정서·판결문을 사건 근거자료로 쓰려면 Claude에게 **"이 판정서(판례)를 ○○ 폴더에 PDF로 저장해 줘"** 라고 하면 됩니다(`save_pdf`).

| 자료 | 저장되는 PDF | 들어가는 정보 |
|---|---|---|
| **질병판정서** | 근로복지공단 질병판정서 사이트의 **[프린트] 화면 그대로** | 공단 양식, **공식 판정번호·판정일**, 모든 쪽 아래에 **출력 일시·원본 주소·쪽 번호** |
| **판례** | 근로복지공단 산재판례 사이트의 **[프린트] 화면 그대로** | 법원·재판부, 당사자, **변론종결일·선고일**, 모든 쪽 아래에 **출력 일시·원본 주소·쪽 번호** |
| **심사결정서** | 공개 화면이 없어 API 원문을 그대로 옮긴 **'원문 출력본'** | 출처, 출력 일시, '공식 문서 아님' 안내, 본문 원문 |

- **파일 이름 예:** `질병판정서_2019판정제2667호_인정_우측퇴행성슬관절염.pdf`, `판례_전주지방법원_2014구합2765_취소_요양결정처분취소.pdf`
- **저장 위치:** 폴더를 말하지 않으면 `내 문서\comwel_PDF` 에 저장합니다. 같은 이름이 있으면 `_2` 를 붙여 덮어쓰지 않습니다.
- **한 번에 최대 20건**까지 저장합니다. 공단 사이트에 부담을 주지 않도록 건마다 잠깐씩 쉽니다(1건에 약 5~10초).
- 공단 사이트에서 찾지 못하면 보관본의 원문으로 '원문 출력본'을 만들고, 파일 이름에 `원문출력본` 을 붙여 구별합니다.
  없는 번호를 넣으면 오류 화면을 저장하지 않고 '실패'로 알려 줍니다.

> **주의:** 이 PDF는 공개 사이트를 인쇄한 **공개 자료 출력본**이며, 근로복지공단이 발급한 공식 문서(정본·등본)가 아닙니다.
> 노동위원회·공단·법원에 낼 때 어떤 형식이 받아들여지는지는 제출처 실무에 따라 다를 수 있으니 사용자가 판단해 주세요.

**필요한 것:** PC에 **Edge 또는 Chrome**이 있으면 됩니다(Windows에는 Edge가 기본 설치). comwel이 브라우저를 **화면 없이 잠깐 실행해 인쇄만** 시키는 방식이라
**Claude in Chrome 같은 확장 프로그램은 필요 없습니다.** 브라우저를 못 찾으면 환경변수 `COMWEL_PDF_BROWSER` 에 실행 파일 경로를 넣어 주세요.

**직접 저장하는 방법(브라우저가 없거나 한 건만 받을 때):**
1. 질병판정서는 `https://jilbyungcase.comwel.or.kr/service/dataView?id=판정위사건번호`,
   판례는 `https://sanjaecase.comwel.or.kr/service/dataView?id=사건번호_법원명` 을 엽니다
   (예: `...?id=540020190002667`, `...?id=2014구합2765_전주지방법원`).
2. 오른쪽 위 **[프린트]** → 인쇄 대상에서 **'PDF로 저장'** 을 고릅니다.

## 설치 방법 (Windows) — Claude에게 맡기기

설치 파일을 실행하지 않습니다. **Claude Code**(Claude 데스크톱 앱의 Code 탭 또는 터미널의 `claude`)에게 설치를 맡깁니다.

### 1단계. 공공데이터포털 인증키 받기 (무료, 5분)

1. [공공데이터포털](https://www.data.go.kr)에 회원가입·로그인합니다.
2. 아래 세 페이지에서 각각 **[활용신청]** 을 누릅니다. 자동승인이라 바로 처리됩니다.
   - [근로복지공단_질병판정서 조회 서비스](https://www.data.go.kr/data/15110836/openapi.do)
   - [근로복지공단_심사결정서 조회 서비스](https://www.data.go.kr/data/15110818/openapi.do)
   - [근로복지공단_산재보험 판례 판결문 조회 서비스](https://www.data.go.kr/data/15041878/openapi.do)
3. **마이페이지 → 개발계정**에서 **일반 인증키(Decoding)** 를 확인해 둡니다. 세 API에 같은 키를 씁니다.

> 인증키는 본인 것만 쓰고 다른 사람과 나누지 마세요. 하루 호출 한도(API마다 10,000번)가 키마다 따로 계산됩니다.

### 2단계. Claude Code에 이 문장을 붙여넣기

```
https://github.com/cplalks-create/comwel-mcp 설치해 줘. 저장소의 INSTALL_FOR_CLAUDE.md 절차를 그대로 따라 줘.
```

Claude가 [설치 지침서](INSTALL_FOR_CLAUDE.md)를 읽고 아래 일을 순서대로 합니다. 중간에 허락을 구하는 창이 뜨면 확인하고 허용해 주세요.

- 프로그램 내려받기 (`C:\Users\내 이름\tools\comwel-mcp`)
- 파이썬 확인과 필요한 패키지 설치 (파이썬이 없으면 설치를 안내합니다)
- **인증키 입력창 띄우기** — 터미널에 뜨는 입력창에 1단계의 키를 붙여넣고 Enter. 입력한 글자는 `*`로 가려지고, 대화창에는 키가 남지 않습니다
  > 대화창에 키를 직접 붙여넣지 마세요.
- 판례 전체 내려받기 (1~2분, 약 500MB)
- Claude Code에 등록 (모든 폴더에서 사용)

### 3단계. 새 대화 열기

설치가 끝나면 **새 대화(새 세션)를 열어** 위 사용 예처럼 질문해 보세요.
Claude 데스크톱 앱의 **채팅**에서도 쓰고 싶으면 설치할 때 Claude에게 "채팅에서도 쓰게 해 줘"라고 하세요.

> Claude Code를 쓰지 않는다면 문서 끝의 [부록: Claude Code 없이 설치하기](#부록-claude-code-없이-설치하기)를 보세요.

| 삭제 | "comwel 삭제해 줘" (지침서의 삭제 절차대로, 폴더 삭제 전에 확인을 받습니다) |

### 판례 자동 갱신

판례 API에는 날짜 칸이 없어서 새 판례만 골라 받을 수 없습니다. 그래서 Claude를 켤 때 뒤에서 아래처럼 확인합니다.

| 상황 | 하는 일 | 공단 서버 호출 |
|---|---|---|
| 마지막 확인 후 7일 이내 | 아무것도 하지 않음 | 0번 |
| 7일 지남 + 판례 건수 같음 | 확인만 하고 끝 | 1번 |
| 7일 지남 + 판례 건수 바뀜 | 전체를 다시 받음 (1~2분) | 약 35번 |
| 마지막으로 받은 지 30일 지남 | 건수가 같아도 다시 받음 (내용만 고쳐진 경우 대비) | 약 35번 |
| 공단 서버 오류 | 기존 보관본을 그대로 쓰고, 하루 뒤 다시 시도 | — |

- 받는 동안에도 검색은 기존 보관본으로 계속됩니다. Claude 창이 여러 개여도 한 곳에서만 받습니다.
- 받는 동안 임시 파일이 잠깐 약 500MB 더 생겼다가, 끝나면 정리됩니다.
- 검색 결과 아래에 "판례 보관본 기준: ○월 ○일"이 표시됩니다. 서면에 인용할 때는 원문을 확인한 날짜를 함께 남겨 두세요.
- 자동 갱신을 끄려면 사용자 환경변수 `COMWEL_AUTO_UPDATE` 를 `0` 으로 설정합니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 파이썬을 찾지 못함 | 파이썬 설치 때 "Add python.exe to PATH"를 체크했는지 확인하고, 다시 설치한 뒤 PC를 재시작 |
| "등록되지 않은 서비스키" 또는 [실패] 403 | 세 API 모두 활용신청을 했는지, **Decoding** 키를 넣었는지 확인. 신청 직후에는 반영까지 최대 1시간 걸릴 수 있음 |
| Claude에서 도구가 안 보임 | 새 대화(새 세션)를 열기. 데스크톱 앱 채팅이라면 앱을 트레이에서 완전히 종료한 뒤 다시 켜기 |
| "판례 보관본이 아직 없습니다" | Claude를 다시 켜면 자동으로 받습니다(1~2분). 바로 받으려면 Claude에게 "판례 보관본 지금 업데이트해 줘" |

## 부록: Claude Code 없이 설치하기

평소에는 위 [설치 방법](#설치-방법-windows--claude에게-맡기기)대로 Claude Code에게 맡기면 됩니다.
아래는 Claude Code를 쓰지 않는 경우의 예비 방법입니다.

### Windows — 설치 파일(install.bat)

1. 이 페이지의 **[Code] → [Download ZIP]** 으로 받아, 앞으로 옮기지 않을 위치(예: `C:\tools\comwel-mcp`)에 압축을 풉니다.
2. `install.bat` 을 더블클릭합니다. "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다.
3. 안내에 따라 인증키를 붙여넣습니다(`*`로 가려짐). 패키지 설치 → 인증키 확인 → 판례 내려받기 → Claude 데스크톱 앱·Claude Code 등록이 차례로 진행됩니다.
4. 끝나면 Claude를 완전히 종료했다가 다시 켭니다.

### Mac·Linux — 수동 설치

```bash
python3 -m pip install -r requirements.txt
export DATA_GO_KR_KEY="발급받은 Decoding 키"
python3 src/check_key.py            # 키 확인
python3 src/sync_precedents.py      # 판례 내려받기
claude mcp add --scope user comwel --env DATA_GO_KR_KEY="발급받은 Decoding 키" -- python3 -X utf8 "$(pwd)/src/server.py"
```

Claude 데스크톱 앱은 `~/Library/Application Support/Claude/claude_desktop_config.json` 의 `mcpServers` 에
`"comwel": {"command": "python3", "args": ["-X", "utf8", "<폴더>/src/server.py"], "env": {"DATA_GO_KR_KEY": "<키>"}}` 를 추가합니다.

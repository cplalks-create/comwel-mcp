# comwel-mcp — 근로복지공단 산재판례·업무상질병판정서 MCP

Claude가 **근로복지공단의 산재 판례 판결문**과 **업무상질병판정위원회 질병판정서**를 직접 검색하고, 원문을 읽고,
인용할 문장이 원문과 글자 그대로 같은지 대조할 수 있게 해 주는 MCP 서버입니다.

> - 근로복지공단의 공식 도구가 아닙니다. 공단이 [공공데이터포털](https://www.data.go.kr)에 공개한 API를 이용하는 개인 제작 도구입니다.
> - 검색 결과는 판단을 돕는 참고 자료이며 법률 자문이 아닙니다. 서면에 인용할 때는 반드시 원문을 확인하세요.

## 무엇을 할 수 있나요

Claude에게 이렇게 물어보면 됩니다.

- "급식실 조리흄 폐암으로 **인정**된 질병판정서 찾아줘"
- "교대제 근무자 뇌출혈 산재 판례 중 공단 처분이 **취소**된 사건 보여 줘"
- "판정위 사건번호 240020210001716 판정서 전문 보여 줘"
- "이 문장이 판결문 원문과 똑같은지 확인해 줘: …"

| 자료 | 공공데이터포털 API | 건수(2026. 10. 기준) | 검색 방식 |
|---|---|---|---|
| 업무상질병 판정서 | [근로복지공단_질병판정서 조회 서비스](https://www.data.go.kr/data/15110836/openapi.do) | 약 6만 1천 건 | 공단 서버에서 실시간 검색 |
| 산재 판례 판결문 | [근로복지공단_산재보험 판례 판결문 조회 서비스](https://www.data.go.kr/data/15041878/openapi.do) | 약 3만 5천 건 | 설치할 때 전체를 PC에 받아 두고 검색 (API에 검색어 기능이 없음) |

### 도구(기능) 목록

| 도구 | 하는 일 |
|---|---|
| `search_disease_rulings` | 질병판정서 검색 — 본문 검색어, 업종(산재보험 사업종류), 심의결과, 질병구분, 직종 |
| `get_disease_ruling` | 질병판정서 전문 보기 (한 번 검색해 본 판정서만 열 수 있음 — API에 사건번호 조회 기능이 없음) |
| `search_precedents` | 판례 검색 — 본문 검색어, 판결결과, 사건유형, 사고/질병 구분, 법원, 사건명 |
| `get_precedent` | 판결문 전문 보기 |
| `verify_quote` | 인용하려는 문장이 원문에 글자 그대로 있는지 대조 (띄어쓰기·줄바꿈 차이만 무시) |
| `list_codes` | 검색 조건에 넣을 분류 값과 건수 보기 |
| `update_precedents` | PC에 받아 둔 판례를 최신 자료로 다시 받기 (1~2분) |

### 검색어 쓰는 법

| 쓰는 법 | 뜻 | 예 |
|---|---|---|
| 낱말을 띄어 씀 | 모두 들어 있는 문서(AND) | `조리흄 폐암` |
| "따옴표" | 한 덩어리 구절 | `"업무상 재해"` |
| -낱말 | 그 낱말이 든 문서 제외 | `폐암 -흡연` |

## 자료의 한계 (꼭 읽어 주세요)

실제 데이터를 조회해 확인한 사항입니다.

- **날짜가 없습니다.** 판례에는 선고일, 판정서에는 판정일 칸이 없습니다. 서면에 날짜를 쓸 때는 따로 확인해야 합니다.
- **정신질환·자살 판정서는 사실상 공개되지 않았습니다.** 공개 판정서 중 정신질환 2건, 자해행위(자살 포함) 2건뿐입니다.
- **판례 약 6,500건은 '취하' 사건**이라 판결문 본문이 없습니다.
- **판결결과는 공단 처분을 기준으로 적혀 있습니다.** 기각 = 대개 근로자 패소, 취소 = 대개 근로자 승소입니다.
- **판정서 검색은 띄어쓰기를 구분합니다.** "조리흄"과 "조리 흄"은 각각 찾아야 합니다. (판례 검색은 띄어쓰기를 무시합니다.)
- 판정서의 '업종'은 사업장 이름이 아니라 **산재보험 사업종류 이름**입니다. (예: 학교급식 → "국가 및 지방자치단체의 사업")
- 판정서·판결문의 개인정보는 공단이 ○○○ 등으로 가려 두었습니다.

## 설치 방법 (Windows)

### 준비물

1. **Claude 데스크톱 앱** 또는 **Claude Code**
2. **파이썬 3.10 이상** — [python.org](https://www.python.org/downloads/)에서 설치합니다.
   설치 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**하세요.
3. **공공데이터포털 인증키** (무료, 아래 1단계)

### 1단계. 공공데이터포털 인증키 받기

1. [공공데이터포털](https://www.data.go.kr)에 회원가입·로그인합니다.
2. 아래 두 페이지에서 각각 **[활용신청]** 을 누릅니다. 자동승인이라 바로 처리됩니다.
   - [근로복지공단_질병판정서 조회 서비스](https://www.data.go.kr/data/15110836/openapi.do)
   - [근로복지공단_산재보험 판례 판결문 조회 서비스](https://www.data.go.kr/data/15041878/openapi.do)
3. **마이페이지 → 개발계정**에서 **일반 인증키(Decoding)** 를 복사해 둡니다. 두 API에 같은 키를 씁니다.

> 인증키는 본인 것만 쓰고 다른 사람과 나누지 마세요. 하루 호출 한도(API마다 10,000번)가 키마다 따로 계산됩니다.

### 2단계. 이 프로그램 내려받기

1. 이 페이지 위쪽의 초록색 **[Code] → [Download ZIP]** 을 누릅니다.
2. 압축을 풀어 **앞으로 옮기지 않을 위치**에 둡니다. (예: `C:\tools\comwel-mcp`)
   설치할 때 이 위치가 Claude에 등록되므로, 나중에 폴더를 옮기면 설치를 다시 해야 합니다.

### 3단계. 설치 파일 실행

1. 압축을 푼 폴더의 **`install.bat`** 을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]** 을 누릅니다.
2. 안내에 따라 1단계의 인증키를 붙여넣고 Enter를 누릅니다. 입력한 글자는 `*`로 가려집니다.
3. 설치 파일이 아래 일을 순서대로 합니다.
   - 패키지 설치
   - 인증키 확인
   - 판례 전체 내려받기 (1~2분, 약 500MB)
   - Claude에 등록 (데스크톱 앱과 Claude Code 중 깔려 있는 쪽에 모두)

### 4단계. Claude 다시 켜기

Claude를 **완전히 종료**(작업 표시줄 트레이 아이콘에서 종료)했다가 다시 켭니다.
새 대화에서 "산재 판례 검색 도구 있어?"라고 물어보거나, 위 사용 예처럼 질문해 보세요.

## 관리

| 하고 싶은 일 | 방법 |
|---|---|
| 판례를 최신으로 | Claude에게 "판례 보관본 업데이트해 줘"라고 하거나 `install.bat` 을 다시 실행 |
| 인증키 바꾸기 | `install.bat` 을 다시 실행해 "그대로 쓸까요?"에 `n` |
| 삭제 | ① Claude 데스크톱 앱: `%APPDATA%\Claude\claude_desktop_config.json` 에서 `comwel` 항목 삭제 ② Claude Code: `claude mcp remove comwel --scope user` ③ 폴더 삭제 ④ (선택) 사용자 환경변수 `DATA_GO_KR_KEY` 삭제 |

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "파이썬을 찾지 못했습니다" | 파이썬 설치 때 "Add python.exe to PATH"를 체크했는지 확인하고, 다시 설치한 뒤 PC를 재시작 |
| "등록되지 않은 서비스키" | 두 API 모두 활용신청을 했는지, **Decoding** 키를 넣었는지 확인. 신청 직후에는 반영까지 최대 1시간 걸릴 수 있음 |
| Claude에서 도구가 안 보임 | Claude를 트레이에서 완전히 종료한 뒤 다시 켜기 |
| "판례 보관본이 아직 없습니다" | `install.bat` 다시 실행, 또는 Claude에게 "판례 보관본 업데이트해 줘" |

## Mac·Linux (수동 설치)

```bash
python3 -m pip install -r requirements.txt
export DATA_GO_KR_KEY="발급받은 Decoding 키"
python3 src/check_key.py            # 키 확인
python3 src/sync_precedents.py      # 판례 내려받기
claude mcp add --scope user comwel --env DATA_GO_KR_KEY="발급받은 Decoding 키" -- python3 -X utf8 "$(pwd)/src/server.py"
```

Claude 데스크톱 앱은 `~/Library/Application Support/Claude/claude_desktop_config.json` 의 `mcpServers` 에
`"comwel": {"command": "python3", "args": ["-X", "utf8", "<폴더>/src/server.py"], "env": {"DATA_GO_KR_KEY": "<키>"}}` 를 추가합니다.
